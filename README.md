# 广告投放渠道效果聚类分析

广告渠道投了不少，但不同渠道的量和质差别很大，预算怎么分？这个项目用 KMeans 对 889 个广告投放渠道做聚类，把渠道分成几类角色，再据此给投放组合提优化建议。

## 数据

`data/ad_performance.csv`，889 条渠道记录，13 个字段：

- 渠道代号
- 数值指标 7 个：日均 UV、注册率、平均搜索量、访问深度、平均停留时间、订单转化率、投放时间
- 类别字段 5 个：素材类型、广告类型、合作方式、广告尺寸、广告卖点

## 分析思路

1. 数据审查：缺失值检查、描述性统计、相关性分析
2. 特征处理：
   - "访问深度"和"平均停留时间"相关性很高（r≈0.76），两者作用重叠，删掉"平均停留时间"
   - 5 个类别字段做 One-Hot 编码
   - 6 个数值指标做 Min-Max 标准化
3. KMeans 聚类：遍历 K=2~7，用平均轮廓系数选最优 K，最终 K=4
4. 聚类画像：各类别的样本量、占比、数值特征均值、类别字段众数，配合雷达图对比

## 主要结论

四类渠道的占比和特征（详见 notebook）：

| 类别 | 占比 | 特征 | 定位 |
| --- | --- | --- | --- |
| 引流拉新型 | 17% | 日均 UV、注册率高 | 拉新、扩大曝光 |
| 订单转化型 | 35% | 搜索量、转化率好，UV 偏低 | 促成交、订单转化 |
| 均衡型 | 39% | 各项指标偏低 | 效果一般，投放价值要重新评估 |
| 通用型 | 8% | 各项中等、不突出 | 各场景可用 |

占比 39% 的渠道各项效果指标都偏低，是首先要审视的对象；引流和转化分开看，预算按渠道角色分配，而不是一刀切。
